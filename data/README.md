# Your data

Backups written by the popup's **Save backup (profiles + history)** button go
here, so a second machine gets everything this one has learned.

```
poker-advisor-backup-2026-10-21.json
```

One file holds all of it: opponent profiles, hand history, and the decision log
the learning engine reads. Load it on the other PC with **Load backup…**.

Keep the repository **private** while these files are in it. They hold named
players' gameplay records and your own results.
